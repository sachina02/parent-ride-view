# MySchoolBus Dashboard

Create a frontend-only project called MySchoolBus using HTML, CSS, and JavaScript only.

Build only the Parent Dashboard for a school bus tracking app.

Include:

Header with MySchoolBus logo/name

Student profile card

Assigned bus and route

Bus status: On Route

ETA card

Pickup stop

Student status: Boarded

Simple mock live-tracking map/card showing a bus, route, and 3 bus stops

Notifications section

Recent trip section

Responsive mobile-friendly design

Use only mock data. No backend, database, authentication, API, or real GPS.

Keep the code simple and do not create extra pages or features yet.
